# Chọn bộ UI cho redesign IncomSG

Đối chiếu tài liệu chính thức và mã nguồn ngày 17/11/2026.

**Đề xuất dùng shadcn/ui chính thức với Radix làm nền chung.** IncomSG đã có React 19, Vite, React Router, Tailwind CSS v4, Radix và Phosphor. Lấy từng thành phần theo nhu cầu, tái sử dụng các primitive và icon đang có, rồi đưa màu, kiểu chữ, bo góc và focus về token của IncomSG. Cách này tận dụng stack và component hiện tại. Đổi lại, team bảo trì phần mã shadcn đã đưa vào repo và tự tích hợp hành vi bảng, form và điều hướng với ứng dụng. [Dependencies hiện tại](../../apps/frontend/package.json) · [Component UI hiện tại](../../apps/frontend/src/components/ui) · [shadcn/ui cho Vite](https://ui.shadcn.com/docs/installation/vite#existing-project) · [React 19 và Tailwind v4](https://ui.shadcn.com/docs/tailwind-v4) · [Theming](https://ui.shadcn.com/docs/theming) · [Registry Radix và Base UI](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/README.md)

## Áp dụng vào các màn hình hiện có

- **Storefront và Member**. Tiếp tục phát triển `StorefrontShellLayout` theo route `/s/:slug`. Tự thiết kế header desktop, thanh điều hướng dưới trên mobile, safe area và trạng thái active khi đi vào route con. Dùng token theo shop cho màu thương hiệu và các cặp màu chữ/nền đủ tương phản. Dùng component chung cho bộ lọc, dialog, form và thẻ. Bố cục danh sách, chi tiết sản phẩm, giỏ hàng, checkout, ví điểm, thử thách và voucher cần phục vụ hành trình riêng của IncomSG. Kiểm tra Sheet/Dialog render qua portal nhận đúng màu shop. [Router hiện tại](../../apps/frontend/src/app/App.tsx) · [StorefrontShellLayout](../../apps/frontend/src/features/storefront/StorefrontShellLayout.tsx) · [Theming](https://ui.shadcn.com/docs/theming)
- **Merchant và Admin**. Dùng `sidebar-05` làm mẫu cho nhóm điều hướng có thể thu gọn trong `BackendConsoleLayout`. Kết nối mục đang mở, breadcrumb và thao tác với React Router và quyền hiện tại. Giữ uPlot cho số liệu đang dùng. Chuẩn hóa toolbar, bộ lọc, trạng thái trống/lỗi, pagination và thao tác theo hàng. Dùng TanStack Table ở những màn cần bộ tính năng bảng lặp lại, nối filter, sort và pagination với API tương ứng khi API hỗ trợ. Thiết kế riêng cách hiển thị bảng trên mobile và màn chi tiết duyệt theo nghiệp vụ. [BackendConsoleLayout](../../apps/frontend/src/layouts/BackendConsoleLayout.tsx) · [Demo sidebar-05](https://ui.shadcn.com/view/new-york-v4/sidebar-05) · [Demo dashboard-01](https://ui.shadcn.com/view/new-york-v4/dashboard-01) · [Xử lý dữ liệu phía server với TanStack Table](https://tanstack.com/table/latest/docs/guide/client-side-vs-server-side)
- **Thử trên hai màn hình trước khi mở rộng**. Bắt đầu từ danh mục một shop và luồng danh sách → chi tiết đơn hàng của Merchant. Kiểm tra thay đổi shop, active state của bottom nav, luồng bàn phím và focus, mật độ bảng desktop, điều hướng mobile và luồng xem chi tiết với API thật. Sau đó mở rộng các kiểu bố cục đã thử sang các màn còn lại, giữ API hiện có làm nguồn trạng thái cho đơn hàng và loyalty.
